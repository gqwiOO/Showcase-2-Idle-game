# CursorUnityShared — переносими правила для Unity

Ця папка містить правила та промпт для Cursor AI, щоб вони автоматично застосовувались у будь-якому Unity-проєкті.

## Що всередині

- **`.cursor/rules/unity-architecture.mdc`** — правило для Cursor (архітектура MVC+Service, Zenject, іменування тощо).
- **`UNITY_AI_PROMPT.md`** — повний промпт з правилами та довідковим кодом.

## Як використовувати в іншому проєкті

1. **Скопіюй вміст цієї папки** в **корінь** цільового Unity-проєкту (туди, де лежать `Assets`, `Packages`, `ProjectSettings`).
2. Під час копіювання:
   - папка `.cursor` зливається з уже наявною (якщо є) — тобто додаються/оновлюються файли в `.cursor/rules/`;
   - файл `UNITY_AI_PROMPT.md` потрапляє в корінь проєкту.
3. Відкрий проєкт у Cursor — правила підхопляться автоматично (Cursor читає `.cursor/rules/` у корені workspace).

Підсумкова структура в проєкті після копіювання:

```
YourUnityProject/
  Assets/
  Packages/
  ProjectSettings/
  .cursor/
    rules/
      unity-architecture.mdc
  UNITY_AI_PROMPT.md
```

## Зберігання однієї копії між проєктами

Можна зберігати папку `CursorUnityShared` в одному місці (наприклад, у Documents, OneDrive або окремому репозиторії) і щоразу копіювати **її вміст** в корінь нового або існуючого Unity-проєкту. Тоді всі проєкти використовуватимуть однакові правила без дублювання самого промпту.
